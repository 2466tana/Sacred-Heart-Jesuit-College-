# Sacred Heart Jesuit College Website

A responsive single-page school website built with plain HTML, CSS, and JavaScript.

## Preview

Open `index.html` in a browser. The page uses remote Unsplash images; an internet connection is needed to load them.

## Customize before publishing

- Replace the example admissions email (`admissions@example.com`) with the school's actual contact address.
- Confirm the school description, mission language, and page links reflect the school's official information.
- Swap the illustrative photography for approved school images.

The site is static and can be deployed with GitHub Pages or any static web host.
